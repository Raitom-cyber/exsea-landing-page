# コンテキスト保存ルール（必ず守る）

AIエージェントにつなぐのは **このフォルダ（速戦ゼミ/）丸ごと**。
新しいコンテキストを入れるときは、必ず下のどこに置くかを先に決める。

| 置き場 | 入れるもの | 判断のしかた |
|---|---|---|
| `context/raw/` | 議事録・メモ・スクショの**原本** | 手を加えていない一次情報。上書き禁止 |
| `context/web/` | Web記事・参考URL | 外から取ってきた情報。URLと取得日を書く |
| `context/md/` | **人が整理した** Markdown | raw を読みやすくまとめ直したもの |
| `context/ai/` | **AIの**要約・下書き | AIが生成したもの。人の確認前の扱い |
| `output/` | 人に渡す成果物 | 完成版だけ。下書きは ai/ に置く |
| `logs/` | 作業・検査の記録 | 日付ファイル（YYYY-MM-DD.md）に追記 |
| `rules/` | 方針・制約・禁止事項 | このファイルなど。AIが最初に読む |

## 運用ルール
1. **原本と加工物を混ぜない**：raw → md/ai → output の順に流れる。逆流させない。
2. **人が書いたか / AIが書いたかを分ける**：md/ は人、ai/ は AI。
3. ファイル名は `YYYY-MM-DD_内容.md`（画像も同じ）。
4. 作業したら `logs/` に1行でも残す。
5. ノート同士は Obsidian の `[[リンク]]` でつなぐ。frontmatter に `tags` を付ける。
6. 秘密情報（パスワード・個人情報）は入れない。
