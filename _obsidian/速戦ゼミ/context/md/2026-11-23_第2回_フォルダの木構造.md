# 第2回：実例 フォルダの木構造

講師例の作成先：`/Users/sennin/Documents/tasks/速戦ゼミ/演習/フォルダ構造/`

```
フォルダ構造/   ← AIエージェントにつなぐ
├── context/   参考資料・背景
│   ├── raw/   議事録・メモの原本
│   ├── web/   Web記事・参考URL
│   ├── md/    整理したMarkdown
│   └── ai/    AIの要約・下書き
├── output/    人に渡す成果物
├── logs/      作業・検査の記録
└── rules/     方針・制約・禁止事項
```

## ポイント
- エージェントには**フォルダ単位**で渡す → 置き場所そのものがAIへの指示になる。
- 原本（raw）と、人の整理（md）、AIの生成物（ai）を分けておくと、どれが信頼できる情報か迷わない。
- 成果物（output）・記録（logs）・ルール（rules）はcontextと別階層。
